# 🔐 Secure Password Evaluator & Generator

A lightweight, CLI-based security utility built in Python to evaluate password complexity and generate cryptographically secure passwords.

---

### ✨ Features
- **Entropy & Complexity Analysis:** Evaluates length, casing, numbers, and symbols.
- **Cryptographic Security:** Leverages Python's built-in `secrets` module instead of standard pseudo-random generators to prevent predictability.
- **Actionable Feedback:** Provides instant security scoring and recommendations to remediate weak credentials.
